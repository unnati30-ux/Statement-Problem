## 📌 Problem Statement

Create a **Python-based Voice Recording System** that can record audio from the user's microphone for a specified duration, save the recorded audio as a `.wav` file, and play the recorded audio back.

The project aims to demonstrate the use of Python libraries such as **SoundDevice** and **SciPy** for capturing, processing, storing, and playing audio. It provides a simple way to understand how audio recording and playback can be implemented using Python.
